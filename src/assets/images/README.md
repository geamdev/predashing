# Imágenes de la landing

Coloca aquí las imágenes del sitio (hero, logos, instructores, íconos, etc.).

Luego impórtalas directamente en los componentes, por ejemplo:

```tsx
import heroImage from "@/assets/images/hero.png"
```

Formatos recomendados: `.webp` o `.png` optimizados, y `.svg` para íconos/logos.
